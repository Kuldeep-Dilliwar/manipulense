# Truth Lens

"Build a React app called ManipuLens. User can either paste any text directly OR enter a URL link. If URL is entered, app fetches the text content from that link. App sends the text to Claude API which identifies psychological manipulation techniques — fear mongering, false urgency, appeal to authority, bandwagon, gaslighting, cherry picking. Highlight each technique in the original text with different colors. Show a manipulation score out of 100. Show explanation cards below for each technique found."
